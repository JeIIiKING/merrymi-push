방송 알림 테스트 페이지 — 매일 밤 9시 ON AIR 알림이 이 기기에 오는지 확인해요.

확인 중…

기기: -

아이폰은 홈 화면에 추가해야 알림이 와요

  1. 사파리 하단 공유 버튼(네모+화살표) 누르기
  2. 홈 화면에 추가 선택 → 추가
  3. 홈 화면에 생긴 메리미 아이콘으로 다시 열기
  4. 거기서 방송 알림 받기 누르기

iOS 16.4 이상 필요. 사파리 탭에서는 알림이 오지 않는 게 정상이에요.

알림 등록

내 기기로 테스트

30초 뒤 보내기를 누르고 바로 브라우저를 완전히 닫아보세요 (최근 앱 목록에서 밀어서 종료). 알림이 오면 성공!

갤럭시: 알림이 늦거나 안 오면

  1. 설정 → 배터리 → 백그라운드 사용 제한
  2. 절전 예외 앱에 지금 쓰는 브라우저(Chrome 또는 삼성 인터넷) 추가
  3. '사용하지 않는 앱 절전/해제 상태'에 브라우저가 있으면 빼기
  4. 브라우저 설정 → 사이트 설정 → 알림에서 이 사이트가 허용인지 확인

알림이 차단돼 있어요
